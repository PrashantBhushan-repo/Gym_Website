## Contact Form Features
- First name, last name, email, phone, and message fields
- Interest selection options:
  - Gym Membership
  - Personal Training
  - Group Classes
  - Nutrition Counseling
  - Free Day Pass
  - Other

## Nearby Gym Search
- Users can enter their location address to find nearby collaborated gym centers.
- The site searches for gyms within 15 km.
- Nearby gyms are displayed as selectable options in the contact form.

## Membership Payment and Requests
- Optional membership payment fields appear in the contact form:
  - Membership plan
  - Payment ID
  - Order ID
  - Generated password
  - Request code
  - Amount paid
- Role request options allow users to request member or trainer account access.
- Admin reviews membership and trainer requests.
