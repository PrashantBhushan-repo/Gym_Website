### Step 1: Identify Target Role

### Step 2: Select 3-5 Bullets from Relevant Section
```
From Full-Stack section:

```

### Step 3: Customize with Real Numbers
```
❌ "Built full-stack application"
✅ "Built full-stack MERN SaaS serving 500+ users with 99.9% uptime 
   and <200ms API latency"
```

### Step 4: Tailor to Job Description
```
Job Description mentions: "experience with AI integration"
→ Add RAG pipeline bullet

Job Description mentions: "optimizing database performance"
→ Add query optimization bullet

Job Description mentions: "AWS experience"
→ Change AWS Bedrock mention, add AWS benefit
```

### Step 5: Keep Consistent Formatting
```
✓ Each bullet: 1 achievement + 2-3 metrics
✓ Action verb: "Designed", "Implemented", "Built", "Optimized"
✓ Metric or impact: Numbers, percentages, reduction/growth
✓ Technical depth: Specific tech (React 18, Pinecone, bcryptjs)
```
