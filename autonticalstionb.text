🚀 Setup Instructions
Step 1: Get Google OAuth Credentials
Go to Google Cloud Console
Create a new project or select existing
Enable Google+ API and Google OAuth2 API
Go to Credentials → Create Credentials → OAuth 2.0 Client IDs
Set Application type: Web application
Add Authorized redirect URIs:
https://gym-website-xtj6.onrender.com/auth/google/callback
http://localhost:5000/auth/google/callback (for local testing)

Copy Client ID and Client Secret
Step 2: Add Environment Variables to Render
Go to your Render backend service → Environment → Add these variables:


Key	Value
GOOGLE_CLIENT_ID	Your Google Client ID
GOOGLE_CLIENT_SECRET	Your Google Client Secret
SESSION_SECRET	your-super-secret-session-key-here-change-this
FRONTEND_URL	https://gym-website-eight-plum.vercel.app
