# 🚀 AI Fitness Assistant Setup Guide - Step by Step

## 📋 **OVERVIEW**
This guide will walk you through setting up the AI Fitness Assistant from scratch. We'll cover AWS Bedrock, Pinecone, environment variables, and deployment. Each step includes detailed instructions with what to click and what to expect.

## 🔧 **STEP 1: AWS BEDROCK SETUP**

### **1.1 Create AWS Account (if you don't have one)**
1. Go to [aws.amazon.com](https://aws.amazon.com)
2. Click **"Create an AWS Account"**
3. Fill in your email, password, and account name
4. Add your contact information and payment method
5. Verify your phone number
6. Choose your support plan (free tier is fine)
7. **Wait for account activation** (can take 24 hours)

### **1.2 Sign into AWS Console**
1. Go to [console.aws.amazon.com](https://console.aws.amazon.com)
2. Sign in with your email and password
3. **Important**: Make sure you're in the **"us-east-1" (N. Virginia)** region
   - Click the region dropdown (top right)
   - Select "US East (N. Virginia)"

### **1.3 Request Access to Amazon Bedrock**
1. In the AWS Console search bar, type **"Bedrock"** and click it
2. Click **"Get started"** if it's your first time
3. In the left sidebar, click **"Model access"**
4. Click **"Modify model access"** (orange button)
5. **Check the boxes** for these models:
   - ✅ **Anthropic** → Claude v2
   - ✅ **Meta** → Llama 2 Chat 13B
   - ✅ **Amazon** → Titan Embeddings G1 - Text v1
6. Click **"Next"**
7. Review and click **"Submit"**
8. **Wait for approval** - this can take 5-10 minutes
   - You'll see "In progress" status
   - Refresh the page until it shows "Access granted"

### **1.4 Create IAM User for Bedrock**
1. In AWS Console search bar, type **"IAM"** and click it
2. In left sidebar, click **"Users"**
3. Click **"Create user"** (orange button)
4. **User details:**
   - User name: `gym-ai-assistant`
   - Check ✅ "Provide user access to the AWS Management Console"
   - Leave console password as "Autogenerated password"
   - Uncheck ✅ "Users must create a new password at next sign-in"
5. Click **"Next"**
6. **Permissions:**
   - Click **"Attach policies directly"**
   - Click **"Create policy"** (this opens a new tab)
   - In the new tab, click **"JSON"** tab
   - Copy and paste this policy:

```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "bedrock:InvokeModel",
                "bedrock:InvokeModelWithResponseStream"
            ],
            "Resource": "*"
        }
    ]
}
```

   - Click **"Next: Tags"**
   - Click **"Next: Review"**
   - Policy name: `BedrockGymAssistantPolicy`
   - Click **"Create policy"**
   - Close the policy tab
   - Back in the user creation tab, click the refresh button 🔄
   - Search for and check ✅ `BedrockGymAssistantPolicy`
7. Click **"Next"**
8. Click **"Create user"**
9. **Important**: Download the CSV file with credentials
   - This contains your Access Key ID and Secret Access Key
   - **Save this file securely** - you'll need it later
   - If you lose it, you'll need to create new credentials

### **1.5 Verify Bedrock Access**
1. Go back to Bedrock console
2. Click **"Playgrounds"** in left sidebar
3. Click **"Text"** under "Chat"
4. Select **"Claude v2"** from dropdown
5. Type "Hello" and click **"Run"**
6. You should see a response from Claude

## 🌲 **STEP 2: PINECONE SETUP**

### **2.1 Create Pinecone Account**
1. Go to [pinecone.io](https://pinecone.io)
2. Click **"Sign Up"** (top right)
3. Sign up with your email (Google/GitHub login works too)
4. Verify your email if required
5. You'll be taken to the dashboard

### **2.2 Create Pinecone Index**
1. In Pinecone dashboard, click **"Create Index"** (big green button)
2. **Index configuration:**
   - **Name**: `gym-knowledge`
   - **Dimensions**: `1536`
   - **Metric**: `cosine`
   - **Pod Type**: `Starter` (free)
   - **Pods**: `1`
3. Click **"Create Index"**
4. Wait for the index to be created (usually 1-2 minutes)
5. Once created, click on the index name `gym-knowledge`
6. Copy the **"Environment"** value (looks like `us-east1-gcp`)
7. Click **"API Keys"** in left sidebar
8. Click **"Create API Key"**
9. **Key details:**
   - Name: `gym-assistant-key`
   - Permissions: `Read/Write`
10. Click **"Create"**
11. **Copy and save** the API key - you'll need it later

## ⚙️ **STEP 3: ENVIRONMENT VARIABLES SETUP**

### **3.1 Locate the .env.example file**
1. Open your project folder: `c:\Users\prash\OneDrive\Desktop\Gym_Website`
2. You should see `AI_IMPLEMENTATION_NOTES.md` and `.env.example`
3. If you don't see `.env.example`, check if it exists in the root folder

### **3.2 Create .env file**
1. Right-click in the project root folder
2. Select **"New"** → **"Text Document"**
3. Name it `.env` (make sure it has no extension)
4. If Windows hides extensions, rename it to `.env.` (with dot at end) then remove the last dot

### **3.3 Fill in Environment Variables**
Open the `.env` file and copy this template, then fill in your values:

```env
# Database - You already have this from your existing setup
MONGO_URI=mongodb+srv://your_username:your_password@cluster.mongodb.net/gym_website

# AWS Bedrock - NEW (from step 1.4)
AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
AWS_REGION=us-east-1

# Pinecone - NEW (from step 2.2)
PINECONE_API_KEY=your_pinecone_api_key_here
PINECONE_INDEX_NAME=gym-knowledge

# Email - You already have this
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_app_password
EMAIL_SERVICE=gmail

# Session - You already have this
SESSION_SECRET=your_secure_random_session_secret

# Google OAuth - You already have this
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GOOGLE_CALLBACK_URL=http://localhost:5000/auth/google/callback

# Razorpay - You already have this
RAZORPAY_KEY_ID=your_razorpay_key_id
RAZORPAY_KEY_SECRET=your_razorpay_key_secret

# Frontend URLs - Update with your Vercel URL later
FRONTEND_URL=http://localhost:3000,https://your-vercel-app.vercel.app

# DNS Servers (optional)
DNS_SERVERS=8.8.8.8,8.8.4.4
```

**Where to find each value:**

- **MONGO_URI**: From your MongoDB Atlas dashboard → Connect → Connect your application → Copy the connection string
- **AWS_ACCESS_KEY_ID & AWS_SECRET_ACCESS_KEY**: From the CSV file you downloaded in step 1.4
- **PINECONE_API_KEY**: From step 2.2 when you created the API key
- **EMAIL_USER & EMAIL_PASS**: Your Gmail and app password (you already have this)
- **SESSION_SECRET**: Any random string, like `my-super-secret-session-key-12345`
- **GOOGLE_CLIENT_ID & SECRET**: From your Google Cloud Console (you already have this)
- **RAZORPAY_KEY_ID & SECRET**: From your Razorpay dashboard (you already have this)
- **FRONTEND_URL**: Leave as is for now, update after Vercel deployment

### **3.4 Verify .env file**
1. Make sure there are no spaces around the `=` signs
2. Save the file
3. **Important**: Never commit this file to Git - it's in `.gitignore`

## 🚀 **STEP 5: DEPLOYMENT**

### **5.1 Deploy Backend to Render**

#### **Create Render Account**
1. Go to [render.com](https://render.com)
2. Sign up with GitHub (recommended)
3. Authorize Render to access your repositories

#### **Deploy Backend**
1. In Render dashboard, click **"New"** → **"Web Service"**
2. Connect your GitHub repository: `PrashantBhushan-repo/Gym_Website`
3. **Service configuration:**
   - **Name**: `gym-backend`
   - **Root Directory**: `backend`
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
4. Click **"Advanced"**
5. Add all environment variables from your `.env` file:
   - Click **"Add Environment Variable"** for each one
   - Copy exact variable names and values
6. Click **"Create Web Service"**
7. Wait for deployment (5-10 minutes)
8. Once deployed, copy the **service URL** (looks like `https://gym-backend.onrender.com`)

### **5.2 Deploy Frontend to Vercel**

#### **Connect to Vercel**
1. Your frontend should already be connected to Vercel from previous setup
2. Go to [vercel.com](https://vercel.com)
3. Sign in and go to your dashboard
4. Find your gym website project

#### **Update Environment Variables**
1. In Vercel dashboard, click on your project
2. Go to **"Settings"** tab
3. Click **"Environment Variables"**
4. Add this variable:
   - **Name**: `REACT_APP_API_URL`
   - **Value**: Your Render backend URL (from step 5.1)
   - **Environment**: `Production`
5. Click **"Save"**

#### **Redeploy Frontend**
1. Go to **"Deployments"** tab
2. Click **"Redeploy"** on the latest deployment
3. Wait for deployment to complete
4. Copy the **frontend URL** (looks like `https://gym-website-xyz.vercel.app`)

### **5.3 Update Backend Environment**
1. Go back to Render dashboard
2. Click on your backend service
3. Go to **"Environment"** tab
4. Update `FRONTEND_URL` to include your Vercel URL:
   ```
   FRONTEND_URL=http://localhost:3000,https://your-vercel-app.vercel.app
   ```
5. Click **"Save Changes"**
6. The backend will automatically redeploy

## 🔍 **STEP 7: TROUBLESHOOTING**

### **If Chat Doesn't Work:**

#### **Check Backend Logs**
1. Go to Render dashboard → Your backend service
2. Click **"Logs"** tab
3. Look for errors

#### **Common Issues:**

**"Bedrock access denied"**
- Go back to AWS Bedrock → Model access
- Make sure all 3 models are approved

**"Pinecone connection failed"**
- Check your Pinecone API key
- Verify index name is `gym-knowledge`

**"MongoDB connection error"**
- Check your MONGO_URI in Render environment variables
- Make sure MongoDB Atlas allows connections from Render IPs

**"CORS error"**
- Update FRONTEND_URL in Render with your exact Vercel URL

### **Debug Commands:**
```bash
# Test backend syntax
cd backend && node --check server.js

# Test environment variables
cd backend && node -e "console.log(process.env.AWS_ACCESS_KEY_ID ? 'AWS OK' : 'AWS Missing')"

# Test MongoDB connection
cd backend && node -e "require('mongoose').connect(process.env.MONGO_URI).then(() => console.log('MongoDB OK')).catch(console.error)"
```
